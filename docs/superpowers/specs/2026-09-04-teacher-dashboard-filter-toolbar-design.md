# 교사 대시보드 필터 도구막대 디자인

## 목적

교사가 독서록 목록을 확인할 때, 실제 내용에 비해 과도하게 넓은 필터 선택 상자로 인해 시선이 분산되는 문제를 해결한다. 제출 독서록을 빠르게 처리하는 `검토 대기` 진입점도 필터와 한 덩어리로 인지되도록 정리한다.

## 범위

- 교사 대시보드의 상태·학급·학생 필터와 검토 대기 버튼의 시각적 배치만 바꾼다.
- 필터 동작, 대기열 API, 정렬, 목록·학생 화면·데이터베이스 스키마는 바꾸지 않는다.

## 레이아웃

### 넓은 화면

- 필터와 검토 대기를 하나의 `toolbar` 행으로 배치한다.
- 상태 선택 상자는 고정된 좁은 폭(약 8.5rem), 학급·학생 선택 상자는 중간 폭(약 10rem)으로 제한한다.
- 검토 대기 버튼은 행의 오른쪽으로 밀어내고, 제출 건수와 화살표를 함께 표시한다.
- 도구막대는 목록과 분리되는 은은한 배경·테두리·내부 여백을 가진다.

### 좁은 화면

- 도구막대는 자연스럽게 줄바꿈한다.
- 상태·학급·학생 필터는 최소 폭을 유지해 읽기 좋게 배치한다.
- 검토 대기 버튼은 다음 줄에서 가로 전체 폭을 사용한다.

## 시각적 위계

- 필터는 기본 표면색과 가는 테두리를 유지해 보조 제어로 둔다.
- 검토 대기는 짙은 `forest` 배경, 밝은 글자, 건수 배지 또는 굵은 숫자로 처리해 가장 먼저 눈에 들어오게 한다.
- 대기열이 비어 있으면 같은 위치를 유지하되, 밝은 표면색·테두리·낮은 대비로 비활성 상태를 표현한다. 버튼의 위치가 바뀌지 않아 화면 구조가 안정적이다.
- 키보드 포커스와 비활성 상태의 대비를 기존 디자인 토큰에 맞춰 유지한다.

## 상호작용

- 필터의 선택·조회 동작은 현재와 같다.
- 활성 `검토 대기 n건`을 누르면 현재의 대기열 첫 독서록으로 이동한다.
- 대기열이 비어 있으면 버튼은 비활성화되며 이동하지 않는다.

## 검증 기준

- 넓은 화면에서 세 필터는 전체 폭을 균등 점유하지 않는다.
- 검토 대기 버튼은 필터와 같은 도구막대 안에 있고, 오른쪽 끝에서 명확히 구분된다.
- 좁은 화면에서 가로 스크롤이 생기지 않고, 검토 대기 버튼은 읽기 쉬운 폭을 확보한다.
- 기존 필터·대기열 동작 회귀 테스트를 유지한다.
